# Calculator Project

An Interactive Web Calculator built using HTML, CSS, and JavaScript that performs basic arithmetic operations through a clean and responsive user interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Responsive design
* Interactive user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Live Demo

 https://zoyanaushad.github.io/Calculator-project/

## Purpose

This project was developed to strengthen JavaScript fundamentals, DOM manipulation, and front-end development skills through the implementation of a functional calculator.
